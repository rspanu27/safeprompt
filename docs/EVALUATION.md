stack trace, and uses that to raise the severity of some findings. For
example, an email address in a production log probably belongs to a real

This accuracy figure is weaker evidence than the detector numbers above. The
same person wrote the classifier and labelled the samples, and there are
fewer than fifty of them, so it mostly shows that the two agree. It is mainly
useful in CI, where it catches changes that break classification.
